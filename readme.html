VICT Site User Manual

1. Purpose of the Site

The VICT site is used to manage Computational Thinking learning resources, registrations, assessment question banks, assessment entry, and assessment dashboards for the Vision Empower VICT program.

The usual workflow is:

  1. Review learning outcomes.
  2. Review games and question banks.
  3. Register schools, facilitators, and students.
  4. Enter assessment observations for students.
  5. Review assessment summaries and analysis in the dashboard.

2. Home Page

Open index.html to access the main site navigation. The home page is grouped into About VICT Program and Monitoring and Evaluation. Use the Home button on each page to return to the home page.

3. Outcomes Page

Use the Outcomes page to view the master list of Computational Thinking outcomes and suboutcomes. These outcomes are used in the question bank and assessment entry pages.

4. Games Page

Use the Games page to view the VICT games master, game details, level, primary CT skill, observation guidance, How to Play information, and game levels.

5. FAQs Page

Use the FAQs page to add, edit, delete, and view frequently asked questions for the VICT program.

6. Registrations Page

Use the Registrations page to manage schools, facilitators, and students. Choose the registration type from the dropdown at the top of the page.

6.1 School Registration

Fields include State, District, School name, Address, and School type. Add, delete, and XLS upload require the admin passcode. Editing an existing school does not require a passcode.

6.2 Facilitator Registration

Fields include States, First name, Last name, Email ID, Phone numbers, Designation, Qualification, Special Educator, and Educator. A facilitator can be assigned to more than one state.

6.3 Student Registration

Fields include State, District, School, Student ID, Name, Gender, Grade, Board of Education, Vision level, Regional Language, disability and Braille-related fields, and computer-related fields. Add, delete, and XLS upload require the admin passcode. Editing an existing student does not require a passcode.

The student table is paginated. Use Previous and Next to move through large student lists. Grade must be a number from 1 to 10.

7. Assessment Question Bank

Use the Assessment Question Bank page to create question bank sets and maintain questions.

Click Create Question Bank, enter the question bank name, and create it. New question banks are created in English by default.

Click the question bank name to view details. Only English question banks allow adding questions. For each question, enter Primary Outcome, Question level, Question order, Total marks, Question text, optional picture, and Correct answer. Question edits are open, while deletes require the question-bank admin passcode.

8. Assessment Entry

Use Assessment Entry to record one student assessment. Read the Note to the Assessors section before beginning.

8.1 Student Details

Select State, School, Grade, Student Name, Assessment Date, and Facilitator. Assessment Date cannot be a future date. If only one facilitator is available for the selected state, the facilitator is preselected.

8.2 Assessment Details

Select Level 1, Level 2, or Level 3. Questions for that level are shown grouped under CT outcomes. For each question, select marks: 0, 0.25, 0.5, 0.75, or 1.

8.3 Subskill Observation Status

For each CT subskill, select Tested and Observed, Tested and Not Observed, or Not tested. Each subskill status is mandatory.

The overall CT outcome rating is calculated automatically: 0 or 1 observed subskills is Missing, 2 or 3 observed subskills is Adequate, and all 4 observed subskills is Acquired.

8.4 Free Play

Free Play is shown for Level 2 and Level 3. Mark it as Satisfactory or Needs improvement.

8.5 Observations and Accuracy

Use Any other observations to write about the student's knowledge level, skills, confidence, speed, and any other notable observations.

Accuracy score should be High when assessment was done in person by the facilitator. Mark Low if there was guess work or the assessor is not sure about the scores.

8.6 Preview and Save

Use Preview assessment to review the entry. When saving, the site shows a confirmation preview. Confirm to submit. If there is an error, the entered data is preserved as a draft.

9. Assessment Dashboard

Use the Assessment Dashboard to review assessment data, download full history CSV, and view assessment analysis.

Student Level analysis shows all assessments for a student in descending date order and progress over time when multiple assessments exist. School, State, and VE Level analysis use each student's latest completed assessment for aggregate counts.

10. Language Dropdown

The site has a language dropdown for English, Hindi, Tamil, Marathi, Kannada, Gujarathi, Telugu, Malayalam, Odiya, Bengali, and Assamese.

11. Admin Passcode Protected Actions

Protected actions include school upload, school add, school delete, student upload, student add, student delete, and question delete. Editing existing school, student, and question rows does not require a passcode.

12. Good Practice Checklist

Before assessment, ensure registrations and question banks are ready, prepare tactile materials, and read the assessor notes. During assessment, do not teach, keep the student relaxed, mark scores and subskill statuses carefully, and write detailed observations. After assessment, preview, save, review the dashboard, and download CSV if offline analysis is needed.
